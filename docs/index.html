01 / overview

One seed in, one stream outwhat it does

moonrand does one thing: it turns thirty-two bytes into a seed, the seed into a reproducible stream, and the stream into the shape you asked for — uniform, normal, exponential, log-normal, integers, bits.

The core is ChaCha12: Daniel J. Bernstein's ARX stream cipher, twelve rounds. Not a linear congruential generator — the low bits do not degrade, and a few million draws in a row still show no stripe. One stream runs for 232 blocks of sixty-four bytes; after that you reseed, and it never loops back to the start.

// three methods; everything else grows on top pub(open) trait Rng { fn next_u64(Self) -> UInt64 fn next_u32(Self) -> UInt = _ fn fill(Self, FixedArray[Byte]) -> Unit = _ }

All fourteen functions take the same Rng. Pass a StdRng, or pass your own implementation — the signatures are not tied to a concrete type.

02 / start

Two lines to beginquick start

// 32 bytes. Where they come from is your business let seed : Bytes = @moonseed.bytes(32, @system.source) let rng = @moonrand.seeded(seed[0:]) // from here, every number comes out of this stream let u = @moonrand.uniform(rng, 0.0, 1.0) // [0, 1) let n = @moonrand.randint(rng, 1, 6) // 1..6 let g = @moonrand.gauss(rng, 0.0, 1.0) // N(0, 1)

seeded takes a BytesView and returns a StdRng, which is ChaCha12 under a shorter name. Same bytes, same stream, forever; change one byte and the whole stream changes.

No seed at hand? from_entropy() asks the platform for thirty-two bytes and hands you a stream that cannot be reproduced. This path raises — it does not quietly degrade into something deterministic, it tells you the machine has no entropy.

03 / guarantees

Three, no morewhat it guarantees

01

Bit-for-bit reproducible

One seed, four backends (native / js / wasm / wasm-gc), one sequence of numbers. The RFC 8439 vectors are pinned in the test suite; a single wrong bit turns it red.

02

No hidden state

A generator is a value, not a global singleton. Two streams can sit side by side in one function without touching each other; copy one and it continues from the same place.

03

Entropy is not here

moonrand never touches the operating system. For real randomness, go to moonseed; for reproducibility, go to seeded. Keeping them apart is what stops either from deciding for you.

06 / limits

What it is notthe honest side

Not cryptographically secure

ChaCha12 is fast; it is not a shield. Keys, nonces, one-time passwords — use moonseed's ChaCha20 with platform entropy instead.

No cross-version promise

Bit-for-bit within a version. A major release may swap the core and the stream moves, so pin the version alongside the seed.

No memory management

No internal buffer pool, no unbounded allocation. fill comes from the trait's default implementation; reach for it only when you need it.
