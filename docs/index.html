moonbitstack / moonrand

moonrand

A seedable pseudo-random number generator.

ChaCha12 at the core, the sampling and distributions on top, all of it held to one Rng contract. Thirty-two bytes fix the whole stream — and the same numbers come out bit for bit on native, JS, wasm and wasm-gc.

01 / overview

It starts with a seedwhat it does

moonrand does one thing: it turns a seed into a reproducible stream, and the stream into the shape you asked for — uniform, normal, gamma, Poisson, integers, bits. The default generator needs no configuration; when the algorithm matters, pick one of the nineteen subpackages.

The core is ChaCha12: Daniel J. Bernstein's ARX stream cipher, twelve rounds. Not a linear congruential generator — the low bits do not degrade, and a few million draws in a row still show no stripe. One stream runs for 232 blocks of sixty-four bytes; after that you reseed, and it never loops back to the start.

// three methods; everything else grows on top pub(open) trait Rng { fn next_u64(Self) -> UInt64 fn next_u32(Self) -> UInt32 = _ fn fill(Self, buf : FixedArray[Byte]) -> Unit = _ }

Every sampling and distribution function takes the same Rng. Pass a StdRng, a xoshiro, a PCG, a Mersenne Twister, or your own implementation — the signatures are not tied to a concrete type.

02 / start

Install, then drawquick start

// thirty-two bytes. Where they come from is your business let rng = @moonrand.seeded(b"a seed") // from here, every number comes out of this stream let roll = @moonrand.randint(rng, 1L, 6L) // 1..6 let noise = @moonrand.gauss(rng) // N(0, 1) assert_eq(roll, 5L) assert_eq(noise.to_string(), "0.03498079073290354")

seeded takes a BytesView and returns a StdRng, which is ChaCha12 under a shorter name. Same bytes, same stream, forever; change one byte and the whole stream changes. To use another algorithm, build a type from @xoshiro or @pcg instead: not one line below changes.

No seed at hand? @auto.rng() asks the platform for thirty-two bytes and hands you a stream that cannot be reproduced. This path raises — it does not quietly degrade into something deterministic, it tells you the machine has no entropy.

03 / guarantees

Three, stated plainlywhat it guarantees

01

Bit-for-bit reproducible

One seed, four backends (native / js / wasm / wasm-gc), one sequence of numbers. The RFC 8439 vectors are pinned in the test suite; a single wrong bit turns it red.

02

No hidden state

A generator is a value, not a global singleton. Two streams can sit side by side in one function without touching each other; copy one and it continues from the same place.

03

Entropy is not here

moonrand never touches the operating system. For real randomness, go to moonseed; for reproducibility, go to seeded. Keeping them apart is what stops either from deciding for you.

04 / api

The whole surfaceroot, contract, core

Left is the signature, right is the shape it promises. Functions take Rng first; the types and contracts follow.

05 / demo

Three dishes on this pagedrawn by one seed

These three dishes are not illustrations. How many times the fret band folds, which character sits in the well — both came out of their own stream, just now, and no two wells take the same character. Reload and they change; write the seed under each dish into your code and they stay exactly these three, down to the petal.

06 / limits

What it is notthe honest side

Not cryptographically secure

ChaCha12 is fast; it is not a shield. Keys, nonces, one-time passwords — use moonseed's ChaCha20 with platform entropy instead.

No cross-version promise

Bit-for-bit within a version. A major release may swap the core and the stream moves, so pin the version alongside the seed.

No memory management

No internal buffer pool, no unbounded allocation. fill comes from the trait's default implementation; reach for it only when you need it.
